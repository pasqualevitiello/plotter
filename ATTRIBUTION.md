# Source and attribution

Plotter was extracted from the coss repository into the private [pasqualevitiello/plotter](https://github.com/pasqualevitiello/plotter) repository.

Extraction baseline: coss commit `54c5a6dd2527d91127bd5efd0dfe2ee055570f27` on `codex/blueprint-illustration-studies`.

The extraction preserves the Plotter skill package originally located at `apps/ui/skills/plotter`, the illustration catalogue and related components from `apps/ui/app/plotter`, and the associated generation and export scripts from `apps/ui/scripts`.

The skill’s bundled reference manifest records the source revisions of its approved SVG snapshots. Dated feedback and audits remain under `skills/plotter/references/history/`. Repository paths and routes inside those records describe the original coss context.
