# Assembly motion

- **Artifact:** `index.html`, self-contained inline SVG, CSS, and JavaScript. Native 560 × 440; scales down proportionally. No visible controls. Duration: **8 seconds**.
- **Relationship:** The viewer sees three rigid parts enter a fixed carrier, explaining how icon, label, and status form one row. This is a conceptual exploded UI study, not a manufacturing or loading simulation.
- **Choreography:** 0–0.8 s: exploded hold. Icon places at 0.8–1.7 s, label at 1.35–2.25 s, pill at 1.9–2.8 s. The assembled row holds until 4.7 s. Pill, label, and icon withdraw in reverse order over 4.7–6.5 s; the exploded configuration holds through 8 s. Placement eases to a precise stop without overshoot; withdrawal is slower. Both ends of the loop have identical poses and zero velocity.
- **Drawing:** Preserves original size, geometry, text, monochrome hierarchy, and transparent forms. The label moves 11 units left as it descends; all three descend 137 units. Guides recede as their travel is fulfilled; arrows return only once withdrawal finishes. A moving clearance mask trims underlying lines without painting opaque backgrounds. Only one live copy of each part is visible during playback.
- **Fallback:** The supplied complete exploded comparison is preserved as the deliberate reduced-motion/no-JavaScript still. Preference changes restore it immediately. Playback pauses while offscreen or the document is hidden. `window.study = { duration: 8, seek(seconds) }` pauses at an exact clamped timeline position using the same renderer as normal playback; an explicit review seek can inspect motion even under reduced motion.
- **References inspected:** Supplied drawing, bundled approved INT-02, projection/arrows/dimensions teaching SVGs, and the supplied Plotter motion examples guidance.
