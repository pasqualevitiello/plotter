# Code map

On 2026-11-01 the catalogue was renumbered into one scheme: a three-letter family prefix and a number, without gaps within a family. Study IDs, deep links, and drawing sources did not change. Use this table to read older records, which keep the codes they were written with.

The seven bundled snapshots were renamed with their codes (for example, `P00.svg` became `GEO-01.svg`); their contents and hashes are unchanged.
