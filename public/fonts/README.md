# Plotter fonts

These Cal Sans variable and Paper Mono files were carried over from `cosscom/ui` at commit `54c5a6dd2527d91127bd5efd0dfe2ee055570f27`. Cal Sans is credited to Mark Davis, WORDMARK × Cal.com.

`app/layout.tsx` loads these local files with `next/font/local`. The body supplies `--font-sans` and `--font-mono`; headings use the same Cal Sans family. See `AGENTS.md` for the typography conventions.
